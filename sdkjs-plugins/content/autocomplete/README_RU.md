# Плагин автозаполнения

Этот плагин является примером помощника по вводу для редакторов ONLYOFFICE.

Плагин совместим с [собственными](https://github.com/ONLYOFFICE/DocumentServer) и [настольными](https://github.com/ONLYOFFICE/DesktopEditors) версиями редакторов ONLYOFFICE. Его можно добавить в экземпляры ONLYOFFICE вручную.

## Как использовать

1. Начните вводить текст, и плагин предложит вам варианты. 
2. Нажмите на вариант, который вы хотите вставить в документ.

Обратите внимание, что это системный плагин, поэтому его нельзя увидеть на вкладке «Плагины». 

## Как установить

Подробные инструкции можно найти в [Документации по API ONLYOFFICE](https://api.onlyoffice.com/docs/plugin-and-macros/tutorials/installing/onlyoffice-docs-on-premises/).
