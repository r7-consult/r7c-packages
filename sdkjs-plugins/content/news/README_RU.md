# Плагин новостей

## Обзор

Выполняйте поиск по миллионам статей из разных источников новостей, используя различных поставщиков API новостей. Этот плагин позволяет вам искать статьи по ключевым словам и просматривать главные заголовки по категориям и странам, а затем открывать их прямо в браузере.

Плагин поддерживает несколько поставщиков API новостей. Выберите предпочитаемого провайдера и получите бесплатный ключ API, чтобы начать использовать плагин.

## Особенности

- **Несколько провайдеров**: поддержка GNews и TheNewsAPI с простым переключением провайдеров.
- **Поиск по ключевым словам**: поиск статей по определенным ключевым словам или фразам.
- **Главные заголовки**: просмотрите самые популярные заголовки по категориям (Бизнес, Технологии, Спорт и т. д.).
- **Параметры для конкретного поставщика**: динамический пользовательский интерфейс, который адаптируется к возможностям каждого поставщика.
- **Языковая поддержка**: поддержка нескольких языков (английского, испанского, французского, немецкого и т. д.).
- **Расширенные настройки**: сортировка по дате публикации или релевантности, фильтрация по доменам (TheNewsAPI).
- **Параметры отображения**: выберите, что отображать (доступно для GNews).
- **Прямой доступ**: щелкните любую статью, чтобы открыть ее в новой вкладке браузера.

## Поддерживаемые поставщики

### GNews ([gnews.io](https://gnews.io))
- 100 запросов/день (уровень бесплатного пользования)
- Поиск по названию, описанию или содержанию
- 60 000+ источников новостей

### TheNewsAPI ([thenewsapi.com](https://www.thenewsapi.com))
- 150 запросов/день (уровень бесплатного пользования)
- Фильтровать по конкретным доменам
- Фильтрация на основе локали

## Как использовать

1. **Выберите поставщика**: выберите предпочитаемый поставщик новостей (GNews или TheNewsAPI).
2. **Получите ключ API**: зарегистрируйтесь на веб-сайте выбранного вами провайдера и получите бесплатный ключ API.
3. **Установить плагин**: откройте плагин на вкладке «Плагины» в R7-Office.
4. **Настройка**: введите ключ API при появлении соответствующего запроса.
5. **Поиск**. Используйте вкладку «Поиск», чтобы найти статьи по ключевым словам.
6. **Заголовки**. Используйте вкладку «Главные заголовки», чтобы просматривать новости по категориям.
7. **Открыть статьи**: нажмите на любую статью, чтобы открыть ее в браузере.

### Вкладка «Поиск»

1. Введите ключевые слова в поле поиска.
2. **(только GNews)** Выберите, что отображать, используя флажки (Название, Описание, Содержание).
3. При желании настройте дополнительные параметры (язык, порядок сортировки, домены для TheNewsAPI).
4. Нажмите «Найти» для поиска.

### Вкладка «Лучшие заголовки»

1. При необходимости введите ключевые слова для фильтрации заголовков.
2. Выберите категорию (Общие, Бизнес, Технологии и т. д.).
3. Выберите страну
4. Нажмите «Найти», чтобы просмотреть заголовки.

## Требования

- R7-редактор документов Office
- Подключение к Интернету
- Бесплатный ключ API от выбранного вами провайдера ([gnews.io](https://gnews.io) или [thenewsapi.com](https://www.thenewsapi.com))

## Известные проблемы

- Требуется подключение к Интернету для загрузки статей.
- Ограничения по ставкам API применяются в зависимости от плана вашего провайдера.
- В некоторых регионах может быть ограничен доступ к определенным источникам новостей.
- Каждому провайдеру требуется свой ключ API
