## Обзор

Найдите и исправьте грамматические и стилистические ошибки.

Плагин использует [LanguageTool](https://languagetool.org/), многоязычную программу проверки грамматики и стиля.

Он совместим с [самостоятельными](https://github.com/ONLYOFFICE/DocumentServer) и [настольными](https://github.com/ONLYOFFICE/DesktopEditors) версиями редакторов ONLYOFFICE. Его можно добавить в экземпляры ONLYOFFICE вручную.

## Как использовать

1. Откройте вкладку «Плагины» и нажмите «LanguageTool».
2. Выберите текст, который хотите проверить.
3. Выберите язык (он может быть определен автоматически или установлен вручную). 
4. Альтернативно вы можете вставить текст для исправления вручную. Для этого введите новый текст в поле на левой панели или отредактируйте уже выделенный текст (это повлияет только на перевод, исходный текст останется неизменным). Нажмите «Проверить».
5. Выберите исправления, которые нужно применить к тексту. Они появятся в тексте в поле на левой панели. 
6. Чтобы заменить выделенный текст в документе исправленным текстом из поля, нажмите Заменить.

## Как установить

Подробные инструкции можно найти в [Документации по API ONLYOFFICE](https://api.onlyoffice.com/docs/plugin-and-macros/tutorials/installing/onlyoffice-docs-on-premises/).

## Использование вашего сервиса

Вы можете установить LanguageTool на свой сервер и отправлять на него запросы. 

Для этого вам необходимо изменить URL-адрес переменной `serviceUrl` в файле `./scripts/langTool.js`.
