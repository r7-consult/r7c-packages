## Обзор

Добавляет изображения в документ из открытой коллекции изображений. 

Плагин использует [Pixabay](https://pixabay.com/), сервис, предлагающий изображения, не защищенные авторскими правами.

Pixabay совместим с [автономными](https://github.com/R7-Office/DocumentServer) и [настольными](https://github.com/R7-Office/DesktopEditors) версиями редакторов R7-Office. Его можно добавить в экземпляры R7-Office вручную. 

## Как использовать

1. Откройте вкладку «Плагины» и щелкните Pixabay.
2. Введите ключевые слова для изображений, которые вы хотите найти.
3. Используйте дополнительные настройки, чтобы задать параметры поиска.
4. Нажмите «Поиск». 
5. Нажмите на изображение, чтобы добавить его в документ.

## Как установить

Подробные инструкции можно найти в [Документации по R7-Office API](https://api.R7-Office.com/docs/plugin-and-macros/tutorials/installing/R7-Office-docs-on-premises/).

## Конфигурация

1. Войдите в свою учетную запись на [Pixabay](https://pixabay.com/) или зарегистрируйте новую.
2. Перейдите на страницу [API DOCS](https://pixabay.com/api/docs/).
3. Найдите на странице свой ключ API и вставьте его в указанное поле плагина Pixabay.
