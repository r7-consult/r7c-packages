## Обзор 

Переведите выделенный текст на другие языки.

Плагин использует Google Translate API. Все языки, поддерживаемые сервисом, поддерживаются плагином R7-Office.

По умолчанию он устанавливается в облаке, [собственном размещении](https://github.com/R7-Office/DocumentServer) и [версии для настольных компьютеров](https://github.com/R7-Office/DesktopEditors) редакторов R7-Office. 

## Как использовать

1. Выберите текст, который хотите перевести.
2. Откройте вкладку «Плагины» и нажмите «Переводчик».
3. Выберите язык, на который вы хотите перевести свой текст.

Если вам нужна дополнительная информация о том, как использовать или написать собственный плагин, см. этот https://api.R7-Office.com/docs/plugin-and-macros/get-started/overview/.

## Известные проблемы

* Не работает в Internet Explorer (ошибка № 47773 во внутренней системе отслеживания ошибок).
* Не работает в Китае.
* Не работает в системе XP.
