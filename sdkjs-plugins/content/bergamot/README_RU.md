# Плагин переводчика Bergamot для R7-Office

Плагин автономного машинного перевода для редакторов R7-Office, работающий на базе механизма нейронного машинного перевода Bergamot.

## Особенности

- **Офлайн-перевод**: работает без подключения к Интернету после загрузки моделей.
- **Конфиденциальность**: весь перевод происходит локально в вашем браузере с помощью WebAssembly.
- **Нейронный машинный перевод**: высококачественные переводы с использованием той же технологии, что и Firefox Translations.
- **Многоязычная поддержка**: поддерживает перевод между многими европейскими языками.
- **Автоматическое определение текста**: автоматически переводит выделенный текст в документе.
- **Ручной ввод**: возможность вручную ввести текст для перевода.

## Поддерживаемые языковые пары

Плагин поддерживает перевод между следующими языками:

- английский
- немецкий
- Испанский
- французский
- итальянский
- Португальский
- польский
- Голландский
- Русский
- украинский
- Чешский
- Болгарский
- Эстонский
- Норвежский (Бокмаль и Нюнорск)
- И еще...

## Как это работает

1. **Первое использование**: плагин загружает систему перевода (WASM) и выбранные языковые модели.
2. **Кэширование моделей**: модели кэшируются в вашем браузере для использования в автономном режиме.
3. **Перевод**. Текст переводится локально с помощью нейронного машинного перевода.

## Технические подробности

- Использует [Bergamot Translator](https://github.com/browsermt/bergamot-translator) — порт WebAssembly платформы Marian NMT.
- Модели предоставлены [переводами Mozilla Firefox](https://github.com/mozilla/firefox-translations-models).
- Часть [Проекта Бергамот](https://browser.mt/), финансируемого Европейским Союзом.

## Использование

1. Установите плагин в редакторе R7-Office.
2. Выберите текст, который хотите перевести.
3. Выберите исходный и целевой языки.
4. Нажмите «Вставить в документ», чтобы заменить выделенный текст переводом.
5. Или нажмите «Копировать», чтобы скопировать перевод в буфер обмена.
