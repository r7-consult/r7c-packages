# AI

`AI` adds an AI workspace to R7-Office and helps process text, code, and document content without leaving the editor. The plugin is suitable for quick one-off requests as well as repeatable daily tasks that benefit from prompts, model routing, and reusable assistants.

## What the plugin does

- opens an AI chat directly inside the editor for work with selected text and current context;
- runs built-in actions such as summarizing, translating, rewriting, simplifying, expanding, shortening, and fixing spelling or grammar;
- supports context-menu and toolbar actions, so common operations can be launched in a couple of clicks;
- lets you connect providers, update model lists, and assign models to different task types;
- supports OCR and image-to-text workflows when the selected model provides the required capability;
- allows you to build custom AI assistants for specialized checks, edits, and transformations.

## Why it is useful

The plugin reduces copy-paste between documents and external AI tools. Instead of moving content back and forth, you can review, transform, and refine text where the work is already happening.

This is especially useful when you need to:

- polish drafts, letters, reports, and presentations faster;
- translate or summarize fragments without switching to another service;
- standardize wording across documents;
- automate recurring review scenarios with your own assistant buttons.

## Custom assistants

One of the strongest parts of the plugin is the ability to create your own assistants for recurring tasks.

You can define:

- a short name for the toolbar;
- a prompt with your exact instructions;
- an action mode:
  - `Hint` for suggestions without direct replacement;
  - `Replace` for fast replacement;
  - `Replace + Hint` for replacement with explanation.

This makes the plugin useful not only as a chat interface, but also as a practical layer for document review and controlled text transformation.

## How to start

1. Open the `AI` plugin from the R7-Office toolbar.
2. Go to settings and connect or select a provider and model.
3. Use chat, a built-in action, or a context-menu command on selected content.
4. If the task is repetitive, create a custom assistant and place it on the toolbar.

## Compatibility

- Minimum editor version: `8.2.0`
- Supported editors: text documents, spreadsheets, presentations, and PDF

Some functions depend on the provider and model you configure. For example, OCR, image actions, or certain advanced workflows are available only when the selected model supports them.
