# Плагин R7-Office Mendeley

Плагин Mendeley позволяет пользователям создавать библиографии в редакторах R7-Office, используя [сервис Mendeley](https://www.mendeley.com/).

Плагин предварительно установлен в [R7-Office Workspace](https://www.R7-Office.com/workspace.aspx) (как Enterprise, так и Community Edition), [R7-Office Cloud Service](https://www.R7-Office.com/cloud-office.aspx) и [R7-Office Personal](https://personal.R7-Office.com/). Его также можно установить на [Сервер документов](https://github.com/R7-Office/DocumentServer) вручную.

## Как использовать

1. Поиск ссылок по автору, названию или году.

2. Среди результатов поиска выберите те, которые хотите добавить в документ.

3. Выберите стиль (например, Чикагское руководство, Американская психологическая ассоциация) и язык.

4. Нажмите `Insert citation`.

## Как установить

Доступны два способа установки:

1. Поместите папку с плагином Mendeley (она должна содержать только содержимое папки src) в папку R7-Office Document Server в зависимости от операционной системы:

    Для Linux — `/var/www/R7-Office/documentserver/sdkjs-plugins/`.

    Для Windows — `%ProgramFiles%\R7-Office\DocumentServer\sdkjs-plugins\`.

    Плагины будут доступны всем пользователям R7-Office Document Server.
    Перезапуск службы не требуется.

2. Отредактируйте конфигурацию Сервера документов, добавив следующие строки:

    ```
    var docEditor = новый DocsAPI.DocEditor("placeholder", {
        "editorConfig": {
            "плагины": {
                "автозапуск": [
                    "по возрастанию.{BE5CBF95-C0AD-4842-B157-AC40FEDD9441}",
                    ...
                ],
                "Данные плагинов": [
                    "https://example.com/path/to/mendeley/config.json",
                    ...
                ]
            },
            ...
        },
        ...
    });
    ```

Подробные инструкции также можно найти в [документации R7-Office API](https://api.R7-Office.com/docs/plugin-and-macros/tutorials/installing/R7-Office-docs-on-premises/).

**Важно**: при интеграции R7-Office Document Server со сторонним хранилищем вам необходимо использовать [специальные соединители](https://api.R7-Office.com/editors/plugins) (приложения для интеграции). Если вы скомпилируете соединитель из исходного кода или создадите новый, вы можете добавить плагины с помощью конфигурации Сервера документов. Если вы используете готовые коннекторы (например, из торговых площадок ownCloud/Nextcloud), добавление плагинов через конфигурацию неприменимо. 

## Конфигурация

Вам необходимо будет зарегистрировать приложение.

1. Перейдите по адресу https://dev.mendeley.com/myapps.html..

2. Заполните форму, используя ссылку, указанную в интерфейсе плагина в качестве URL-адреса перенаправления.

3. Нажмите `Generate secret` и скопируйте его.

4. Вставьте секрет в соответствующее поле интерфейса плагина.

## Известные проблемы

Для пользователей CentOS с включенным SELinx после копирования папки src в sdkjs-plugins плагины могут не работать из-за переменного контекста безопасности файла. Для восстановления прав используйте следующую команду:```
sudo restorecon -Rv /var/www/R7-Office/documentserver/sdkjs-plugins/
```
После этого перезапустите службы:```
sudo supervisorctl restart ds:docservice
```
Этот плагин не работает в десктопном редакторе, так как есть проблемы с авторизацией. Мы знаем об этой проблеме и постараемся исправить ее в этой функции.
