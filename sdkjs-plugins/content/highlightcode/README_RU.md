## Обзор

Выделите синтаксис кода, выбрав необходимый язык, стиль и цвет фона.

Плагин использует движок [highlight.js](https://highlightjs.org/), библиотеку [prettier](https://github.com/prettier/prettier), плагин [prettier-plugin-php] (https://github.com/prettier/plugin-php), библиотеку [xml-formatter.js](https://github.com/chrisbottin/xml-formatter) и библиотеку [js-beautify.js](https://github.com/beautify-web/js-beautify). 

Он устанавливается по умолчанию в облаке, [собственном размещении](https://github.com/R7-Office/DocumentServer) и [версии для настольных компьютеров](https://github.com/R7-Office/DesktopEditors) редакторов R7-Office. 
## Поддерживаемые языки и стили

Поддерживаемые языки: Apache, Bash, Shell, Matlab, erlang, Javascript, Profile, Ruby, Prolong, Swift, sql, Java, HTTP, Fortran, Perl, XML, CPP, JSON, CS, Nginx, Basic, Markdown, CSS, Python, Objectivec, php, Delphi. 

Поддерживаемые стили: Googlecode, GitHub, GitHub Gist, Android Studio, Visual Studio, Visual Studio 2015, Idea, Qtcreator Dark, Qtcreator Light, XCode, Fortran, Foundation, XML 1, XML 2. 

## Как использовать

1. Найдите плагин на вкладке Плагины.
2. Введите свой код.
3. Установите язык, который вы используете. Он будет определен автоматически, но вы также можете изменить его вручную. 
4. Выберите стиль/цвет фона и нажмите ОК, чтобы вставить код в документ. 

Если вам нужна дополнительная информация о том, как использовать или написать собственный плагин, см. этот https://api.R7-Office.com/docs/plugin-and-macros/get-started/overview/.
