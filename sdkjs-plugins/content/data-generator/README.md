# Data Generator

`Data Generator` brings this workflow into R7 so the task can be completed faster and with fewer context switches.

## What the plugin does

Generate random or sequential data for cells: numbers, dates, UUIDs, names, emails, and custom sequences.

## When it is useful

- When you want to solve the task directly inside the editor.
- When a repetitive action should take seconds instead of minutes.
- When the team needs a clearer and more predictable workflow.

## Result

The plugin keeps the work inside R7 and turns a routine operation into a faster, more convenient step.
