## Обзор

Импортируйте данные из каналов OData в свою электронную таблицу.

Плагин подключается к сервисам [OData](https://www.odata.org/) и позволяет просматривать доступные наборы сущностей (таблицы), просматривать данные и вставлять их непосредственно в ячейки в виде отформатированных таблиц.

Импорт OData совместим с [автономными](https://github.com/ONLYOFFICE/DocumentServer) и [настольными](https://github.com/ONLYOFFICE/DesktopEditors) версиями редакторов ONLYOFFICE. Его можно добавить в экземпляры ONLYOFFICE вручную.

## Как использовать

1. Перейдите на вкладку «Плагины» и нажмите «Импорт OData».

2. Введите URL-адрес службы OData (например, `https://services.odata.org/V4/Northwind/Northwind.svc`).

3. Нажмите «Получить таблицы», чтобы получить доступные наборы сущностей из службы.

4. Выберите таблицу из списка, чтобы просмотреть ее данные.

5. Нажмите «Вставить», чтобы вставить данные в электронную таблицу, начиная с текущей ячейки.

## Как установить

Подробные инструкции можно найти в [Документации по API ONLYOFFICE](https://api.onlyoffice.com/docs/plugin-and-macros/tutorials/installing/onlyoffice-docs-on-premises/).

## Поддерживаемые версии OData

Плагин поддерживает службы OData v3 и OData v4.
