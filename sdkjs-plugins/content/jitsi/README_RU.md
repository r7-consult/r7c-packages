## Обзор

Совершайте аудио- и видеозвонки прямо в редакторах.

Плагин использует [Jitsi](https://jitsi.org/), инструмент для видео- и аудиоконференций с открытым исходным кодом. 

Плагин совместим с [самостоятельными](https://github.com/R7-Office/DocumentServer) версиями редакторов R7-Office. Его можно добавить в экземпляры R7-Office вручную.

## Как использовать

1. Откройте вкладку «Плагины» и нажмите Jitsi.
2. Нажмите кнопку «Пуск» (для создания Jitsi iframe).
3. Введите свой псевдоним и разрешите браузеру использовать камеру и микрофон.
3. Если вы хотите закрыть Jitsi iframe, нажмите кнопку «Стоп».

## Как установить

Подробные инструкции можно найти в [Документации по R7-Office API](https://api.R7-Office.com/docs/plugin-and-macros/tutorials/installing/R7-Office-docs-on-premises/).

## Известные проблемы

* Плагин не работает с http (работает только с https).
