## Обзор

Получите содержимое документа в виде HTML-кода, измените его и вставьте обратно в документ. 

Этот плагин использует [CodeMirror](https://codemirror.net), универсальный текстовый редактор, реализованный на JavaScript для браузера, и [prettier](https://github.com/prettier/prettier) Prettier — это авторитетный форматировщик кода с поддержкой: JavaScript (включая экспериментальные функции), JSX, Angular, Vue, Flow, TypeScript, CSS, Less и SCSS, HTML, JSON, GraphQL, Markdown, включая GFM и MDX, YAML.

Плагин совместим с [самостоятельными](https://github.com/R7-Office/DocumentServer) и [настольными](https://github.com/R7-Office/DesktopEditors) версиями редакторов R7-Office. Его можно добавить в экземпляры R7-Office вручную. 

## Как использовать

1. Откройте вкладку «Плагины» и нажмите «Получить и вставить html».
2. Выберите необходимый контент.
3. В поле плагина на левой панели вы увидите HTML-код выбранного тезиса.
4. При необходимости измените HTML-код.
5. Нажмите «Вставить в документ», чтобы вставить HTML-код в текущую позицию курсора в документе. 

Вы также можете написать свой собственный HTML-код (не выбирая содержимое документа), а затем вставить его в свой документ.
