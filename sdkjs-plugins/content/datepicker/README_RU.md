Обзор
Вставка отформатированных дат в ячейки электронной таблицы с помощью интерфейса календаря.

Установка
Установите плагин Insert QR из магазина плагинов.
Использование
Активируйте DatePicker:

Перейдите на вкладку плагина.
Активируйте плагин DatePicker в разделе «Плагины».
Выберите ячейки:

Выберите область ячеек, в которой вы хотите напечатать отформатированную дату.
Выберите дату:

Нажмите кнопку «Выбрать дату», чтобы выбрать нужную дату из календаря.
Выберите формат:

Нажмите кнопку «Выбрать формат», чтобы отформатировать ранее выбранную дату.
Распечатайте дату:

Распечатайте отформатированную дату в выбранной области ячейки.
