## Обзор

Преобразование выделенного текста в речь. 

Плагин использует [guessLanguage][1] для распознавания языка и интерфейса [SpeechSynthesis][2] [Web Speech API][3]. 

Плагин Speech по умолчанию устанавливается в облаке и [автономном размещении][4] редакторов R7-Office. 

## Как использовать

1. Выделите здесь нужную фразу.
2. Откройте настройки плагина, чтобы выбрать язык озвучки (настройка по умолчанию — режим автораспознавания).
3. Нажмите на плагин, чтобы озвучить текст

### Примечание

Некоторые браузеры, например. Mozzila и Opera могут использовать для генерации речи только предустановленные в вашей системе языки.
Поэтому, чтобы использовать новые языки, вам необходимо добавить их в свою систему.

### Известные проблемы

* Плагин не работает в Safari 15.3 (17612.4.9.1.8). Проблема исправлена в Safari 15.4 (17614.1.7.7).

Если вам нужна дополнительная информация о том, как использовать или написать собственный плагин, см. этот https://api.R7-Office.com/docs/plugin-and-macros/get-started/overview/.
