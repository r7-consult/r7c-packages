# Плагин ONLYOFFICE Zotero

Плагин Zotero позволяет пользователям создавать библиографии в редакторах ONLYOFFICE с помощью сервиса Zotero.

Плагин предустановлен в ONLYOFFICE Workspace (как Enterprise, так и Community Edition), облачном сервисе ONLYOFFICE и ONLYOFFICE Personal. Его также можно установить на Сервер документов и настольные редакторы вручную.

## Как использовать

1. Поиск ссылок по автору, названию или году.

2. Среди результатов поиска выберите те, которые хотите добавить в документ.

3. Выберите стиль (например, Чикагское руководство, Американская психологическая ассоциация) и язык.

4. Нажмите `Insert citation`.

5. Нажмите кнопку `Insert bibliography`, чтобы добавить или обновить библиографию.

6. Нажмите кнопку `Refresh`, чтобы обновить все поля цитат и библиографии в документе.

7. Если вы хотите открыть этот документ в других редакторах (в которых нет плагина Zotero), вам следует преобразовать все поля в текст. Для этого нажмите кнопку `Unlink citations`.

Обратите внимание, что Zotero работает только с личной библиотекой пользователя, связанной с вашей учетной записью. Желаемые источники необходимо добавить в вашу библиотеку в Zotero, прежде чем вы сможете искать и добавлять их в свою библиографию с помощью плагина.

## Как установить на сервер

Доступны два способа установки:

1. Поместите папку с кодом плагина в папку Сервера документов ONLYOFFICE в зависимости от операционной системы:

    Для Linux — `/var/www/onlyoffice/documentserver/sdkjs-plugins/`.

    Для Windows — `%ProgramFiles%\ONLYOFFICE\DocumentServer\sdkjs-plugins\`.

    Плагины будут доступны всем пользователям Сервера документов ONLYOFFICE.
    Перезапуск службы не требуется.

2. Отредактируйте конфигурацию Сервера документов, добавив следующие строки:

        ```
        var docEditor = новый DocsAPI.DocEditor("placeholder", {
            "editorConfig": {
                "плагины": {
                    "автозапуск": [
                        "по возрастанию.{BFC5D5C6-89DE-4168-9565-ABD8D1E48711}",
                        ...
                    ],
                    "Данные плагинов": [
                        "https://example.com/path/to/zotero/config.json",
                        ...
                    ]
                },
                ...
            },
            ...
        });
        ```

    **Важно**: при интеграции Сервера документов ONLYOFFICE со сторонним хранилищем необходимо использовать специальные коннекторы (приложения для интеграции). Если вы скомпилируете соединитель из исходного кода или создадите новый, вы можете добавить плагины с помощью конфигурации Сервера документов. Если вы используете готовые коннекторы (например, из торговых площадок ownCloud/Nextcloud), добавление плагинов через конфигурацию неприменимо.

## Как установить на рабочий стол

- Заархивируйте файлы плагина (архив должен содержать config.json, index.html и pluginCode.js).
- Измените расширение файла на .plugin.
- Перейдите на вкладку «Плагины», нажмите «Управление плагинами» >> «Добавить плагин», найдите файл .plugin.

## Конфигурация

1. Найдите плагин Zotero на вкладке `Plugins` редактора документов ONLYOFFICE и щелкните его.

2. Войдите в свою учетную запись Zotero.3. Перейдите по ссылке `Zotero API settings` из окна плагина. Если вы вошли в систему, вы сможете продолжить. Если вы не вошли в систему, вы увидите сообщение об ошибке. В этом случае нажмите `Log in` (правый верхний угол экрана).

4. Нажмите `Create new private key`.

5. Введите `Key Description`, убедитесь, что флажок `Allow library access` установлен, и нажмите `Save Key`.

6. Скопируйте вновь созданный ключ и вставьте его в поле `API Key` в интерфейсе плагина и сохраните его.

## Автономный режим

1. [Загрузите](https://www.zotero.org/download/) и установите Zotero Connector.

3. Убедитесь, что API приложения открыт для взаимодействия. (`Edit` -> `Settings` -> `Advanced` -> `Allow other applications on this computer to communicate with Zotero`)

## Известные проблемы

Для пользователей CentOS с включенным SELinx после копирования папки src в sdkjs-plugins плагины могут не работать из-за переменного контекста безопасности файла. Для восстановления прав используйте следующую команду:```
sudo restorecon -Rv /var/www/onlyoffice/documentserver/sdkjs-plugins/
```
После этого перезапустите службы:```
sudo supervisorctl restart ds:docservice
```
