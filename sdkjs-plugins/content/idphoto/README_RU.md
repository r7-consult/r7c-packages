## Введение в проект

Содержимое данного склада представляет собой плагин R7-Office, который также является результатом проекта ОСПП-2024 «Написание плагина для интеграции конвертера ID-фото с R7-Office».

Этот плагин позволяет пользователям конвертировать личные фотографии в фотографии на документы в R7-Office.
