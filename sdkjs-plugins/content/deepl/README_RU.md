## Обзор

Переведите выделенный текст на другие языки.

Плагин использует [DeepL Translator](https://www.deepl.com/translator), бесплатный сервис нейронного машинного перевода.

DeepL совместим с [самостоятельными](https://github.com/R7-Office/DocumentServer) и [настольными](https://github.com/R7-Office/DesktopEditors) версиями редакторов R7-Office. Его можно добавить в экземпляры R7-Office вручную.

## Как использовать

1. Выберите текст, который хотите перевести.

2. Перейдите на вкладку «Плагины» и нажмите DeepL.

3. Выберите целевой язык.

4. Альтернативно вы можете вставить текст для перевода вручную. Для этого нажмите Ввести текст вручную на левой панели. Введите новый текст в появившееся поле или отредактируйте уже выделенный текст (это повлияет только на перевод, исходный текст останется неизменным).

5. Используйте кнопку «Копировать», чтобы скопировать перевод, и кнопку «Заменить», чтобы заменить выделенный текст его переводом.

## Как установить

Подробные инструкции можно найти в [Документации по R7-Office API](https://api.R7-Office.com/docs/plugin-and-macros/tutorials/installing/R7-Office-docs-on-premises/).

## Конфигурация

1. Войдите в свою учетную запись DeepL или создайте новую.
2. Подпишитесь на DeepL API для разработчиков.
3. На [странице плана учетной записи](https://www.deepl.com/pro-account/plan) найдите ключ API и скопируйте его.
4. Вставьте ключ в соответствующее поле интерфейса плагина.
