# Плагин масштабирования

Плагин Zoom позволяет пользователям планировать встречи и совершать звонки.

Он совместим с [самостоятельной](https://github.com/R7-Office/DocumentServer) версией редакторов R7-Office. Его можно добавить в экземпляры R7-Office вручную.

## Как использовать

1. Перейдите на вкладку плагинов и нажмите «Масштаб».
2. Добавьте тему собрания и выберите «Начать собрание» или «Запланировать собрание». 

## Как установить

Подробные инструкции можно найти в [Документации по R7-Office API](https://api.R7-Office.com/docs/plugin-and-macros/tutorials/installing/R7-Office-docs-on-premises/).

## Конфигурация

1. Чтобы использовать расписание встреч, создайте приложение JWT по адресу https://marketplace.zoom.us/develop/create.. Заполните все необходимые поля и активируйте приложение.
2. Чтобы присоединиться к собраниям, создайте приложение Meeting SDK по адресу https://marketplace.zoom.us/develop/create.. Заполните все необходимые поля и активируйте приложение.
2. Скопируйте ключ SDK, секрет SDK и токен JWT из учетных данных приложений JWT и SDK и вставьте их в указанные поля плагина, нажмите «Сохранить».

## Примечание
Для рабочего стола информация о созданной встрече будет добавлена в комментарии к документу, однако в веб-версии она будет отправлена в чат.

## Известные проблемы
При присоединении к собранию в браузере Safari может появиться черное окно. Для того, чтобы проблема исчезла, необходимо изменить размер окна плагина или увеличить масштаб браузера.
