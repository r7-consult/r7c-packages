# Плагин Mathpix для R7-Office

Преобразуйте математические формулы из изображений в редактируемый текст! Этот плагин позволяет вам легко извлекать математические формулы и текст из изображений и вставлять их непосредственно в документы R7-Office.

## 🌟 Ключевые особенности

- **Несколько методов ввода**:
  - Нажмите, чтобы загрузить изображения
  - Поддержка пакетной загрузки нескольких изображений.

- **Умное распознавание**:
  - Автоматическое распознавание математических формул и текста
  - Предварительный просмотр результатов распознавания в реальном времени
  - Поддержка ручного редактирования результатов

- **Гибкие форматы вывода**:
  - LaTeX (идеально подходит для математических формул)
  - Текст
  - МатематикаML
  - HTML

- **Удобные операции**:
  - Результаты копирования в один клик
  - Прямая вставка в документы
  - Поддержка темной темы

## 🚀 Быстрый старт

### 1. Получите ключи API
1. Посетите [Mathpix OCR](https://mathpix.com/ocr), чтобы зарегистрироваться.
2. Получите идентификатор приложения и ключ приложения.

### 2. Настройте плагин
1. Нажмите значок ⚙️ в правом верхнем углу.
2. Введите свой идентификатор приложения и ключ приложения.
3. Нажмите «Сохранить учетные данные».
4. Выберите предпочитаемые форматы вывода (LaTeX и текст включены по умолчанию).

### 3. Использование плагина

#### Загрузить изображения
- Нажмите на область загрузки, чтобы выбрать файлы.
- Выбор нескольких файлов одновременно для пакетной обработки

#### Распознавание и использование
1. Нажмите кнопку «Распознать», чтобы начать обработку.
2. Для каждого результата распознавания:
   - Посмотреть предварительный просмотр
   - Выберите выходной формат из раскрывающегося меню.
   - При необходимости отредактируйте текст распознавания.
   - Используйте «Копировать», чтобы скопировать, или «Вставить», чтобы добавить в документ.

#### Важные примечания
- **При использовании формата LaTeX некоторые сложные математические выражения могут потребовать ручной настройки для работы с редактором документов R7-Office**
- Предварительный просмотр результатов перед вставкой для обеспечения точности
- Если результаты распознавания неудовлетворительны, попробуйте использовать более четкие изображения.

## 💡 Советы по использованию

1. **Пакетная обработка**:
   - Загрузить несколько изображений одновременно
   - На всех изображениях последовательно будут показаны результаты распознавания.

2. **Выбор формата**:
   - LaTeX: лучше всего подходит для математических формул.
   - Текст: подходит для обычного текстового контента.
   - MathML: требования к формату XML.
   - HTML: для удобного для Интернета формата.

3. **Функции редактирования**:
   - Все результаты распознавания доступны для непосредственного редактирования.
   - Внесите необходимые изменения перед вставкой документа.

## 🔧 Системные требования

- R7-редактор документов Office
- Действительные учетные данные API Mathpix.
- Подключение к Интернету

## 🆘 Распространенные проблемы

1. **Ошибка распознавания?**
   - Убедитесь, что учетные данные API верны.
   - Убедитесь, что изображение четкое и читаемое.
   - Проверьте подключение к Интернету

2. **Вставленная формула отображается неправильно?**
   - Попробуйте использовать базовый синтаксис LaTeX.
   - Проверьте наличие неподдерживаемого расширенного синтаксиса.
   - Ручная настройка сложных выражений

3. **Как всё очистить?**
   - Нажмите кнопку «Очистить», чтобы сбросить состояние плагина.
