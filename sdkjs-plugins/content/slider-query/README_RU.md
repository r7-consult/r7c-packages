# Слайдер Данные

`Slider Query` — коммерческий плагин self-service аналитики для табличного редактора R7. Он предназначен для повседневной отчётности, подготовки данных на SQL и OLAP-анализа прямо внутри R7-Office, без постоянного перехода в внешние BI-системы для типовых задач.

Продукт разработан `ООО "Датаконс"` и ориентирован на практическое импортозамещение сценариев, которые в других офисных средах часто закрываются через Power Query, Microsoft Access и Power BI.

## Для чего нужен плагин

`Slider Query` помогает аналитикам и бизнес-пользователям работать с операционными и аналитическими данными в привычном интерфейсе таблицы. Вместо ручных выгрузок, сборки данных в нескольких инструментах и постоянного пересоздания отчётов пользователь получает единый рабочий контур внутри R7.

Плагин особенно полезен для:

- регулярной отчётности и операционной аналитики;
- объединения данных из нескольких систем в одном отчёте;
- построения повторно используемой логики на SQL;
- интерактивной работы с OLAP-кубами и сводными аналитическими представлениями.

## Ключевые возможности

### Менеджер соединений

В плагин встроен отдельный менеджер соединений для настройки и проверки источников данных. Он покрывает работу с реляционными базами, локальными файлами и OLAP-подключениями.

Типовые источники:

- PostgreSQL, MS SQL, MySQL и другие реляционные СУБД;
- Excel, CSV/TXT, JSON, Parquet и каталоги с файлами;
- OLAP/XMLA-источники для многомерной аналитики.

Также поддерживаются импорт и экспорт настроек соединений, что удобно для переноса конфигураций между стендами и аккуратного тиражирования рабочих подключений.

### Менеджер SQL

Менеджер SQL — это основное рабочее пространство для построения и сопровождения отчётной логики. В нём можно создавать запросы, группировать их по источникам, просматривать результаты и использовать готовую логику в регулярных сценариях.

В этом модуле особенно важны:

- создание обычных SQL-отчётов по настроенным источникам;
- предварительный просмотр результата до загрузки на лист;
- использование переменных для динамических отчётов;
- поддержка гетерогенных запросов, объединяющих разные системы;
- построение цепочек обработки, где один подготовленный набор данных становится источником для следующего шага.

### Гетерогенные запросы и объединение источников

Одна из наиболее сильных практических возможностей — объединение данных из разных типов источников в одном аналитическом потоке. В реальной работе это особенно важно, когда отчёт собирается из нескольких систем и форматов сразу.

Это позволяет:

- связывать таблицы из СУБД с локальными файлами;
- собирать консолидированные датасеты для регулярной отчётности;
- переносить часть обработки ближе к источникам и загружать в редактор только итоговый результат.

### OLAP и сводные аналитические отчёты

Для многомерного анализа в плагине есть отдельный OLAP-модуль. Он поддерживает интерактивную работу с кубами, выбор полей, настройку фильтров и формирование сводных представлений прямо из табличного редактора.

Это особенно актуально для:

- ad-hoc анализа;
- управленческой отчётности на базе OLAP-кубов;
- быстрой детализации показателей и измерений без ручной пересборки отчёта.

## Типовые сценарии использования

`Slider Query` особенно уместен, когда:

- отчёты нужно регулярно обновлять из одних и тех же источников;
- данные разнесены по нескольким системам и форматам;
- стандартного импорта таблиц уже недостаточно;
- аналитикам нужны BI-возможности, но без выхода из R7-Таблицы.
