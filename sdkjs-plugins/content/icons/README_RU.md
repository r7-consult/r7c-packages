### Удобный плагин, позволяющий легко вставлять значки Font Awesome в ваши документы.

### Особенности

🔍 Поиск значков в библиотеке Font Awesome  
⚡ Быстрая вставка простым щелчком мыши.  
🎨 Настраиваемый размер, цвет и стиль.  
🔄 Поддержка стилей значков «Обычный», «Сплошной» и «Бренды».

### Сборка```bash
npm i
npm run build:all
```
### Обновление значков Font Awesome (Windows)```bash
cd .dev/svg-path-generator && npm i && npm run start && cd ../..
```
### Browser Support

IE11+
