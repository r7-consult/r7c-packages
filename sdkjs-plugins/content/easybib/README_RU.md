# Плагин EasyBib

Плагин EasyBib позволяет пользователям автоматически добавлять ссылки в документ в полном соответствии с выбранными ими руководствами по стилю.

Плагин предварительно установлен в R7-Office Workspace (Enterprise и Community Edition) и облачном сервисе R7-Office.

## Особенности

* Создание цитат и добавление библиографии.
* Выберите необходимый стиль библиографии: Гарвардский, IEEE, Чикаго или любой другой. 

## Как установить

Подробные инструкции можно найти в [Документации по R7-Office API](https://api.R7-Office.com/docs/plugin-and-macros/tutorials/installing/R7-Office-docs-on-premises/).

## Как использовать

1. Выберите плагин EasyBib на вкладке Плагины.
2. Найдите нужную книгу, журнальную статью или сайт.
3. Выберите стиль библиографии и добавьте библиографию в документ.

Список библиографии начнется там, где вы поместите курсор.

## Конфигурация

1. Перейдите на [страницу регистрации EasyBib](https://api.citation-api.com/signup). 
2. Заполните форму. Вставьте URL-адрес из поля с URL-адресом перенаправления из плагина в поле URL-адреса формы, примите Условия обслуживания и нажмите «Отправить».
3. Вы получите подтверждающее сообщение на указанный адрес электронной почты. Перейдите по ссылке подтверждения;
4. После этого вы получите еще одно сообщение по электронной почте с информацией о вашем заявлении. Скопируйте или запишите `apikey`.
5. Вставьте `apikey` в определенные поля плагина, сохраните.
