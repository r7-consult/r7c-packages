## Обзор

Быстро переведите выделенный текст на другие языки.

Плагин использует [Apertium](https://www.apertium.org/), бесплатную платформу машинного перевода с открытым исходным кодом.

Apertium совместим с [самостоятельными](https://github.com/R7-Office/DocumentServer) и [настольными](https://github.com/R7-Office/DesktopEditors) версиями редакторов R7-Office. Его можно добавить в экземпляры R7-Office вручную. 

## Как использовать

1. Выберите текст, который хотите перевести.

2. Перейдите на вкладку «Плагины» и нажмите «Apertium».

3. Альтернативно вы можете вставить текст для перевода вручную, ничего не меняя в документе. Для этого нажмите Ввести текст вручную на левой панели. Введите новый текст в появившееся поле или отредактируйте уже выделенный текст (это повлияет только на перевод, исходный текст останется неизменным).

4. Используйте кнопку «Копировать», чтобы скопировать перевод, и кнопку «Заменить», чтобы заменить выделенный текст его переводом.

## Как установить

Подробные инструкции можно найти в [Документации по R7-Office API](https://api.R7-Office.com/docs/plugin-and-macros/tutorials/installing/R7-Office-docs-on-premises/).

## Использование собственного сервиса

По умолчанию плагин использует демонстрационный сервис Apertium с ограниченным количеством языковых пар.

Чтобы использовать Apertium без ограничений, установите его на свой сервер.

Чтобы отправлять запросы на перевод на свой сервер, измените URL-адрес переменной `serviceUrl` в файле `./scripts/apertium.js`.

## Знать проблемы

В переводе с английского на сербско-хорватский есть ошибки: в переводе добавлены лишние символы.
