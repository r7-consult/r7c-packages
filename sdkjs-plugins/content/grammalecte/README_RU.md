## Обзор

Правильная французская грамматика и типографика. 

Плагин использует [Grammalecte](https://grammalecte.net/), корректор грамматики и типографики с открытым исходным кодом, предназначенный для французского языка.

Grammalecte совместим с [самостоятельными](https://github.com/R7-Office/DocumentServer) и [настольными](https://github.com/R7-Office/DesktopEditors) версиями редакторов R7-Office. Его можно добавить в экземпляры R7-Office вручную.

## Как использовать

1. Откройте вкладку «Плагины» и нажмите «Grammalecte».
2. Выберите текст, который хотите проверить.
3. Альтернативно вы можете вставить текст для исправления вручную. Для этого введите новый текст в поле на левой панели или отредактируйте уже выделенный текст (это повлияет только на перевод, исходный текст останется неизменным). Нажмите «Проверить».
4. Выберите исправления, которые нужно применить к тексту. Они появятся в тексте в поле на левой панели. 
5. Чтобы заменить выделенный текст в документе исправленным текстом из поля, нажмите Заменить.
