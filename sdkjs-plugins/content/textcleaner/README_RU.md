# Очиститель текста

Умный плагин очистки и форматирования текста для редактора документов R7-Office, который помогает очищать и стандартизировать форматирование текста с помощью расширенных параметров.

## Обзор

Text Cleaner — это интеллектуальный плагин, который выходит за рамки простой функции «очистки форматирования». Он обеспечивает детальный контроль над форматированием текста, сохраняя при этом важные элементы стиля, такие как жирный шрифт и курсив. Плагин предлагает комплексные возможности очистки текста, включая:

- **Умное удаление форматирования**: удалите определенные элементы форматирования, сохранив другие.
- **Стандартизация шрифтов**: применяйте одинаковые семейства и размеры шрифтов во всем документе.
- **Преобразование регистра текста**: несколько вариантов преобразования регистра (регистр предложений, верхний регистр, нижний регистр и т. д.).
- **Специальный контроль форматирования**: управление прописными и маленькими прописными буквами, межбуквенным интервалом и вертикальным выравниванием.
- **Интеграция с контекстным меню**: быстрый доступ к функциям очистки через контекстное меню.

## Особенности

### 🎯 Очистить форматирование
- Удаление жирного шрифта, курсива, подчеркивания и зачеркивания.
- Четкие цвета текста и выделение
- Удаление фона и контурного форматирования.
- Выборочное удаление форматирования с детальным контролем.

### 🔤 Стандартизация шрифтов
- Применяйте согласованные семейства шрифтов (Arial, Calibri, Times New Roman и т. д.).
- Стандартизировать размеры шрифтов (от 8 до 36 пунктов).
- Сбросить расстояние между буквами до значений по умолчанию.
- Сбросить вертикальное смещение текста.

### 📝 Преобразование регистра текста
- **Регистр предложений**: делайте первую букву каждого предложения заглавной.
- **нижний регистр**: преобразовать весь текст в нижний регистр.
- **ВЕРХНИЙ РЕГИСТР**: преобразовать весь текст в верхний регистр.
- **Капитализируйте каждое слово**: делайте первую букву каждого слова заглавной.
- **переключить регистр**: инвертировать регистр каждого символа.
- **Не изменять**: сохранить существующее форматирование регистра.

### ⚙️ Специальное форматирование
- Отключить форматирование ЗАГЛАВНЫМИ БУКВАМИ.
- Отключить форматирование прописными буквами.
- Сбросить выравнивание базовой линии текста.
- Расширенные элементы управления типографикой

### 🎨 Пользовательский интерфейс
- Чистый, интуитивно понятный интерфейс со складными разделами.
- Выберите все параметры одним щелчком мыши
- Предварительный просмотр изменений в реальном времени
- Функция отмены для отмены изменений.
- Загрузка индикаторов во время обработки
- Многоязычная поддержка (более 15 языков)

## Установка

### Магазин плагинов 
1. Откройте редактор документов R7-Office.
2. Перейдите в раздел **Плагины** → **Диспетчер плагинов**.
3. Найдите «Очиститель текста».
4. Нажмите **Установить**.


## Использование

### Базовое использование

1. **Откройте плагин**:
   – Перейдите в раздел **Плагины** → **Очиститель текста**.
   - Или воспользуйтесь контекстным меню: щелкните правой кнопкой мыши → **Очистка текста**.

2. **Выберите текст** (необязательно):
   - Выберите конкретный текст для очистки или
   - Не оставляйте выбор, чтобы очистить весь документ.

3. **Настроить параметры**:
   - Расширьте разделы, которые вы хотите использовать.
   - Установите/снимите флажки с определенных параметров форматирования.
   - Выберите семейство и размер шрифта для стандартизации.
   - Выберите вариант преобразования регистра текста

4. **Применить очистку**:
   – Нажмите кнопку **Очистить**.
   - Дождитесь завершения обработки
   - Обзор результатов

### Расширенное использование

#### Интеграция контекстного меню
- Щелкните правой кнопкой мыши по выделенному тексту.
– Выберите **Очистка текста** в контекстном меню.
- Выберите конкретные варианты очистки
- Применить изменения мгновенно

#### Пакетная обработка- Используйте опцию «Выбрать все», чтобы применить все функции очистки.
- Обработка целых документов с единообразным форматированием
- Используйте функцию отмены, чтобы отменить изменения, если это необходимо.

#### Стандартизация шрифтов
- Выбирайте популярные семейства шрифтов (Arial, Calibri, Times New Roman и т. д.).
- Выберите подходящий размер шрифта для вашего типа документа.
- Примените единообразную типографику по всему документу.

### Советы и лучшие практики

1. **Резервное копирование документа**: всегда сохраняйте резервную копию перед применением значительных изменений форматирования.
2. **Тестирование на небольших разделах**: сначала попробуйте плагин на небольшом выделении текста.
3. **Используйте функцию отмены**: плагин предоставляет функцию отмены для отмены изменений.
4. **Комбинируйте варианты**: комбинируйте различные варианты очистки для достижения оптимальных результатов.
5. **Последовательность шрифтов**. Используйте стандартизацию шрифтов для профессиональных документов.
