# Плагин LizardTypst

Простой плагин для ONLYOFFICE, позволяющий вставлять математические формулы Typst в виде высококачественных SVG-изображений, созданный на основе библиотеки `typst.ts`.

Этот плагин совместим с [собственными](https://github.com/ONLYOFFICE/DocumentServer) и [настольными](https://github.com/ONLYOFFICE/DesktopEditors) версиями редакторов ONLYOFFICE. Его можно добавить в экземпляры ONLYOFFICE вручную.

## Мотивация

Плагин LizardTypst черпает вдохновение из существующего плагина **Iguana LaTeX**. Наша цель — предоставить пользователям Typst современное и доступное решение, используя преимущества Typst непосредственно в ONLYOFFICE, не требуя сложных локальных настроек.

## Особенности

- **Рендеринг в реальном времени**: просмотрите визуализированную формулу Typst в реальном времени по мере ввода. Это обеспечивает немедленный и интерактивный опыт редактирования.
- **Локальная установка не требуется**: в отличие от решений, которые зависят от рендеринга на стороне сервера или локальных установок LaTeX/Typst, LizardTypst использует `typst.ts` для компиляции кода Typst непосредственно в вашем браузере. Это означает, что для использования плагина вам не нужно устанавливать какое-либо дополнительное программное обеспечение на вашем компьютере.
- **Визуализация на основе SVG**: формулы вставляются в виде масштабируемой векторной графики, обеспечивая высокое качество при любом уровне масштабирования.

## При поддержке

Этот плагин использует возможности [typst.ts](https://github.com/myriaddreamin/typst.ts), мощной библиотеки TypeScript для компиляции и рендеринга кода Typst непосредственно в браузере с помощью WebAssembly.

## Зависимости от поставщиков

Этот плагин использует предоставленную поставщиком (самостоятельную) версию `typst.ts` для обеспечения автономной работы.
- **`@myriaddreamin/typst.ts`**: `0.6.1-rc5`

## Как использовать

1. Перейдите на вкладку **Плагины** в редакторе ONLYOFFICE.
2. Нажмите значок **LizardTypst**, чтобы открыть окно плагина.
3. Введите свой код Typst в поле ввода слева. Справа будет создан предварительный просмотр.
4. Если вы удовлетворены результатом, нажмите кнопку **Вставить**, чтобы поместить изображение в документ.
